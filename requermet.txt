# Project: Modern E-Commerce Website

Act as a Senior Frontend Developer and UI/UX Designer. Build a complete, modern, clean, and professional e-commerce website using React.js.

## 1. Technology Stack

Use the following technologies:

- React.js (Vite)
- JavaScript (ES6+)
- JSX file extension only (.jsx)
- React Router  for routing
- Tailwind CSS for styling
- React Icons for icons
- React Hot Toast for notifications (if needed)
- Fake Store API for product data

API Endpoint:
https://fakestoreapi.com/products

Product Details API:
https://fakestoreapi.com/products/{id}

Important:
- Do not use TypeScript.
- Do not use Next.js.
- Do not use unnecessary libraries.
- Write clean, reusable, maintainable React components.
- Use functional components and React Hooks.

## 2. Design Requirements

Create a premium-looking e-commerce website with:

- Minimal and clean UI
- Modern typography
- Professional color palette
- White or light background
- Beautiful spacing and consistent alignment
- Subtle shadows and rounded corners
- Smooth hover effects and transitions
- Professional product cards
- Responsive design for mobile, tablet, and desktop

Design inspiration: Modern premium online shopping websites.

Avoid:
- Overly colorful designs
- Excessive animations
- Cluttered layouts
- Unnecessary gradients
- Generic-looking UI

Make the design visually attractive and production-quality.

## 4. Shopping Cart Functionality

Implement a functional shopping cart.

Features:
- Add products to cart
- Increase/decrease quantity
- Remove products
- Display total items
- Calculate subtotal and total price
- Empty cart state
- Cart page (/cart)
- Continue Shopping button
- Checkout button (UI only; no real payment integration)

Use React Context API for global cart state.

Persist cart data in localStorage so the cart remains after refreshing the browser.

## 7. API Integration

Use Fake Store API:

All Products:
https://fakestoreapi.com/products

Single Product:
https://fakestoreapi.com/products/{id}

Categories:
https://fakestoreapi.com/products/categories

Requirements:
- Use fetch or Axios (prefer fetch).
- Handle loading and error states.
- Avoid unnecessary duplicate API requests.
- Use reusable API logic where appropriate.
- Do not hardcode product information.
- Dynamically render all product data from the API.
